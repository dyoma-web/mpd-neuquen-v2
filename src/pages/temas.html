Mapa de recorridos

Esta página se arma sola con el contenido real del chat. Cada botón lleva siempre a la misma respuesta, y cada recorrido termina en una explicación, una oficina, otro organismo o un mensaje de urgencia.

Primero, la urgenciaAntes de buscar el tema, cada pregunta escrita se revisa por señales de riesgo. Si aparece una, se muestra el mensaje fijo y no se sigue con el recorrido.
Después, los datos personalesSi el texto tiene un DNI, un correo o un número de expediente, el mensaje no se muestra y se pide reformular.
Por último, el temaSe busca la localidad, el tipo de aviso, la ley o el tema. Si no hay coincidencia, el chat lo dice y ofrece alternativas.
